Vibe Coder Bootcamp

Python from zero to NumPy, pandas, PyTorch and attention, for ML interviews. Every exercise runs in your browser and the tests tell you what's wrong. No autocomplete, no AI.

Local edition

Take the bootcamp offline

The same course, running on your own computer. Your progress and every line you write are saved to a file, so clearing the browser or switching browsers loses nothing.

  • Works with no internet and no wait for Python to download
  • Real Python with real NumPy and pandas, plus real PyTorch if you want it
  • Progress tracked on disk in ~/.local/share/vibe-coder-bootcamp/progress.json
  • Private: it only listens on your own machine, and installs nothing system-wide
  1. Get the code
    git clone https://github.com/CaffineAddic/vibe-coder-bootcamp.git cd vibe-coder-bootcamp
  2. Install it (Linux: Arch, Ubuntu, Fedora…; add --torch for real PyTorch)
    ./local/install.sh
  3. Start it, or open Vibe Coder Bootcamp from your app menu
    vibe-bootcamp

On macOS or Windows (WSL), skip step 2 and run python3 local/bootcamp.py. It needs only Python. Install numpy and pandas for Parts 3 and 4.
